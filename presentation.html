PROBLEM DOMAIN & CONSTRAINTS

Problem Domain: Game Dynamics vs Sandbox Constraints

CSES Buckshot Roulette Mechanics

  • Turn-Based Gunplay: Secret chamber sequence of live and blank rounds. Choices: shoot opponent or shoot self.
  • Multi-Agent Crossfire (2-4p): Stochastic turn order and table coalitions cause eliminations before a player can act.
  • Strategic Items: Juice (heal +1), Mag Glass (peek shell), Hand Saw (+1 dmg), Pool Floatie (skip enemy), Coffee (eject shell).
  • Imperfect Information: Chamber sequence is hidden; shots and ejections must be tracked mathematically.

Strict Sandbox Constraints

  • Zero External Dependencies: Evaluation container is python:3.12-slim standard library only (no runtime PyTorch/NumPy).
  • Memory Ceiling: Max 128 MB RAM (eliminates heavy ML runtimes).
  • Per-Decision Timeout: Max 0.05s per turn (prohibits heavy Monte Carlo tree search).
  • Match Time Budget: Max 0.50s cumulative match compute time.
SYSTEM ARCHITECTURE

System Architecture: 5-Stage Zero-Dependency Pipeline

1. Bayesian Shell Observer

Computes exact p_live and p_blank by tracking initial rounds, shots, and ejected shells. Flags 100% certain states without guessing.

2. Pure Python Deep Q-Network

Evaluates Q(s, a) over 18 features via an MLP (18→48→24→7). Exported weights total 65 KB. Inference takes < 0.001s with zero external packages.

3. Action Masking & Targeting

Enforces game invariants (heal if hurt, zero gamble on blanks) and directs fire using Threat-Weighted Anti-Snowball targeting.

STRATEGIC INNOVATIONS

Strategic Innovations: Overcoming Multi-Agent Hazards

Threat-Weighted Anti-Snowball Targeting

The Kingmaker Problem: In 4-player games, naive focus-fire attacks the lowest-HP bot, allowing healthy leaders to free-ride. Team CyberCore targets lethal foes first, then attacks the highest-HP leader holding burst items (hand_saw*3 + floatie*2), maintaining table balance.

Smart Floatie Turn-Denial Logic

The Wasted Floatie Trap: If an opponent is confirmed to die on the current turn from a live shell, pinning them is wasted. CyberCore skips doomed targets and freezes the next surviving threat in turn order, guaranteeing an enemy turn-skip.

Balanced Apex Draft Priority

Utility Diversity: Rather than hoarding only juice, our policy drafts a complete arsenal: (1) Survival (maintain ≥ 2 Juice), (2) Vision (1-2 Mag Glass), (3) Burst (2 Hand Saws), (4) Control (1 Floatie), and (5) Hoard remaining Juice to starve enemies.

Zero-Gamble Shooting Invariant

Risk Minimization: The agent never gambles its life on probability. It shoots self if and only if p_blank == 1.0 (100% mathematically proven free turn). In all uncertain or live states, it directs fire at the opponent.
